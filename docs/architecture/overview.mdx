## Key Architectural Decisions

### Server Components First

We use React Server Components by default, only adding `'use client'` when necessary for:
- Interactive components (buttons, forms)
- Components using browser APIs
- Components with Framer Motion animations

### API Routes

All data mutations go through Next.js API routes in `/src/app/api/`:
- Centralizes business logic
- Enables rate limiting and validation
- Provides consistent error handling

### State Management

Zustand for client state with a unified store pattern:
- Single source of truth for user, progress, and UI state
- Minimal re-renders with selective subscriptions
- Persisted to localStorage where appropriate
