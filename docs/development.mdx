## Code Style

### TypeScript

- Use strict TypeScript with proper typing
- Prefer interfaces over types for object shapes
- Use `type` for unions, intersections, and utility types

### Components

- Use functional components with hooks
- Co-locate component files (Component.tsx, Component.test.tsx)
- Export components as named exports

### Styling

- Use Tailwind CSS with the design system tokens
- Reference CSS variables from `globals.css` for colors
- Never hardcode hex values - always use brand tokens

```tsx
// ✅ Good
<div className="bg-navy text-white">

// ❌ Bad
<div style={{ backgroundColor: '#0A004A' }}>
```

### Animations

- Use Framer Motion for all animations
- Follow the 3-tier timing system:
  - `100ms` for instant feedback
  - `200ms` for standard transitions
  - `400ms` for elaborate animations

```tsx
// Standard transition
<motion.div
  whileHover={{ scale: 1.02 }}
  transition={{ duration: 0.2 }}
>

// Elaborate entrance
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.4 }}
>
```

## Git Workflow

1. Create a feature branch from `main`
2. Make changes and commit with clear messages
3. Run `npm run build` and `npm run lint` before pushing
4. Create a pull request for review

## Testing

```bash
# Run all tests
npm run test

# Run tests in watch mode
npm run test:watch

# Run E2E tests
npm run test:e2e
```
