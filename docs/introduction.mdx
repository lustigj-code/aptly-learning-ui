# Welcome to Aptly Learning

**Design Philosophy**: *"Duolingo Meets Professional Certification"* — Inspired by Headspace and Masterclass.

Aptly Learning is a beautiful, gamified learning platform that makes professional certification engaging and accessible. Built with modern web technologies and a focus on user experience.

## Animation Timing

The UI uses a 3-tier animation system:

| Tier | Duration | Usage |
|------|----------|-------|
| **Instant** | 100ms | Micro-feedback, toggles |
| **Standard** | 200ms | Most transitions |
| **Elaborate** | 400ms | Page transitions, celebrations |
