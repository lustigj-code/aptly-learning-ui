# Enable Required Google Cloud APIs

You need to enable 5 APIs in the Google Cloud Console. Click each link below:

## Step 1: Enable Cloud Functions API
👉 https://console.cloud.google.com/apis/library/cloudfunctions.googleapis.com?project=aptly-study-app

Click **"ENABLE"** button

## Step 2: Enable Cloud Build API
👉 https://console.cloud.google.com/apis/library/cloudbuild.googleapis.com?project=aptly-study-app

Click **"ENABLE"** button

## Step 3: Enable Artifact Registry API
👉 https://console.cloud.google.com/apis/library/artifactregistry.googleapis.com?project=aptly-study-app

Click **"ENABLE"** button

## Step 4: Enable Cloud Scheduler API
👉 https://console.cloud.google.com/apis/library/cloudscheduler.googleapis.com?project=aptly-study-app

Click **"ENABLE"** button

## Step 5: Enable Cloud Pub/Sub API
👉 https://console.cloud.google.com/apis/library/pubsub.googleapis.com?project=aptly-study-app

Click **"ENABLE"** button

## After Enabling All APIs

Wait 30 seconds, then let me know and I'll run the deployment!

Each API takes 10-15 seconds to enable. You'll see a checkmark ✓ when done.
