# Phase 4.2 Plan 01: Course Registry & Infrastructure

## Objective

Create a centralized course registry as the single source of truth for all course data, replacing hard-coded course selection with dynamic lookups.

## Context

Currently the codebase has scattered references to "Social Media Marketing" course content but the user should be learning "AI at Work". Hard-coded if/else statements select courses, and the dashboard/learn pages don't consistently show correct course information.

## Tasks

### Task 1: Create Course Registry
**File:** `src/data/courseRegistry.ts`

Create centralized course registry with:
- Course interface (id, title, description, thumbnail, modules)
- getCourse(courseId) function
- getAllCourses() function
- getDefaultCourse() function
- Module/Lesson lookup functions

### Task 2: Update Dashboard Course Title
**File:** `src/app/dashboard/page.tsx` or related

Ensure dashboard shows the correct course title based on user's enrolled/current course.

### Task 3: Update Learn Page Breadcrumbs
**File:** `src/app/learn/page.tsx` or related

Replace hard-coded breadcrumbs with dynamic lookups from course registry.

### Task 4: Fix User Defaults
**File:** `src/store/unifiedStore.ts` or user creation flow

Ensure new users default to "AI at Work" course, not Social Media Marketing.

### Task 5: Verify Build Passes

Run `npm run build` and fix any TypeScript errors.

## Success Criteria

- [ ] Single courseRegistry.ts file is the source of truth
- [ ] Dashboard shows correct course title
- [ ] Learn page breadcrumbs show correct course/module/lesson names
- [ ] New users start with AI at Work course
- [ ] Build passes without errors

## Dependencies

- Phase 4.1 complete (skill maps in Firestore)
