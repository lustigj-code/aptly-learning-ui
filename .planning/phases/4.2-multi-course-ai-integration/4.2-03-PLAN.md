# Phase 4.2 Plan 03: Prominent AI Features

## Objective

Make AI features visible and accessible throughout the learning experience, not just in the coach chat.

## Context

AI features currently exist but are hidden in the coach chat interface. Users don't realize they can get AI help during learning. Need to surface AI assistance at key moments.

## Tasks

### Task 1: Verify Coach Chat Works
**File:** Various coach-related files

- Test that coach chat responds correctly
- Ensure API endpoints are working
- Fix any broken connections

### Task 2: Add AI Hint Button to QuizAtom
**File:** `src/components/atoms/QuizAtom.tsx` or equivalent

- Add "Get a Hint" button on quiz questions
- Use Socratic approach (guide, don't give answer)
- Show hint in a collapsible panel

### Task 3: Add "Explain Why" After Wrong Answers
**File:** `src/components/atoms/QuizAtom.tsx` or equivalent

- After wrong answer, show "Explain Why" button
- Generate explanation using AI
- Show in feedback area

### Task 4: Add AI Summary Button to ReadingAtom
**File:** `src/components/learning/ReadingAtom.tsx`

- Add "Get AI Summary" button in header
- Generate summary using AI when clicked
- Show in a modal or expandable section

### Task 5: Verify Build Passes

Run `npm run build` and fix any TypeScript errors.
