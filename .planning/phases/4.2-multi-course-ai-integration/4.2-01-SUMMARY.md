# Phase 4.2 Plan 01: Course Registry & Infrastructure Summary

**Course data is now centralized in courseRegistry.ts with dynamic lookups replacing hard-coded course selection.**

## Accomplishments

- Created `courseRegistry.ts` as single source of truth for all course data
- Updated dashboard to show correct course title and modules
- Updated CoachLearningView to dynamically load course content
- Updated user defaults to use AI at Work course

## Files Created

### New
- `src/data/courseRegistry.ts` - Centralized course registry with helper functions

## Files Modified

- `src/app/dashboard/page.tsx` - Uses courseRegistry instead of COURSES array
- `src/components/learning/CoachLearningView.tsx` - Gets module from courseRegistry based on courseId
- `src/store/unifiedStore.ts` - Default progress uses AI at Work course IDs
- `src/app/onboarding/page.tsx` - New users default to AI at Work course

## Key Features

### Course Registry API
```typescript
// Get a course
const course = getCourse('ai-at-work');

// Get default course (AI at Work)
const defaultCourse = getDefaultCourse();

// Get all courses
const courses = getAllCourses();

// Get module by ID
const module = getModule('ai-m1');

// Get lesson with context
const { lesson, moduleId, courseId } = getLessonWithContext('1.1');

// Get atom with full context
const { atom, lessonId, moduleId, courseId } = getAtomWithContext('1.1-intro');

// Generate breadcrumbs
const crumbs = getBreadcrumbs('ai-at-work', 'ai-m1', '1.1');
```

### Dashboard Changes
- Now shows AI at Work course by default
- Learning Path section shows modules instead of Social Media Marketing courses
- Progress calculated from actual module/lesson data

### Learning View Changes
- `getModule()` function now takes courseId and moduleId parameters
- Falls back to first module of course if not specified
- Uses user's currentCourseId from progress if available

### User Defaults
- New users start with:
  - `currentCourseId: 'ai-at-work'`
  - `currentModuleId: 'ai-m1'`
  - `currentLessonId: '1.1'`
  - `currentAtomId: '1.1-intro'`

## Decisions Made

1. **Registry exports both individual and bulk lookups** - getCourse for single, getAllCourses for catalog
2. **Fallback chain for courseId** - props → user progress → DEFAULT_COURSE_ID
3. **Deprecated userStore.ts left unchanged** - it's deprecated, unifiedStore is the source of truth
