# Phase 4.1 Plan 04: Admin Interface for Skill Maps Summary

**Admins can now view, generate, and activate skill maps through a dedicated interface.**

## Accomplishments

- Created admin API endpoints for skill map CRUD operations
- Built list page showing all courses with skill map status
- Built detail page with SkillMapEditor component for viewing skills
- Added generate/regenerate/activate actions
- Fixed auth token access by using `getIdToken()` from firebase auth module

## Files Created

### API Routes
- `src/app/api/admin/skill-maps/route.ts` - GET (list), POST (generate), PATCH (update status)
- `src/app/api/admin/skill-maps/[courseId]/route.ts` - GET detail for single course

### Pages
- `src/app/admin/skill-maps/page.tsx` - List page with course table and actions
- `src/app/admin/skill-maps/[courseId]/page.tsx` - Detail page with skill map viewer

### Components
- `src/components/admin/SkillMapEditor.tsx` - Full skill map viewer with:
  - Skills grouped by module (expandable sections)
  - BKT parameters display (pL0, pT, pG, pS)
  - Difficulty badges (Easy/Medium/Hard inferred from pL0)
  - Status badges
  - Generate/Activate/Regenerate actions

## Features

### List Page
- Shows all courses with their skill map status
- Status badges: No Map, Draft, Approved, Active
- Skills count and generation date
- Generate button for courses without maps
- Activate/Regenerate buttons for draft maps
- View button to navigate to detail page

### Detail Page
- Course info header with module/lesson/skill counts
- Metadata section: status, version, generated date, model used
- Skills by module with expandable sections
- Each skill shows: name, lesson ID, prerequisites, difficulty, BKT params

## API Endpoints

```typescript
// List all courses with skill map status
GET /api/admin/skill-maps

// Generate skill map for a course
POST /api/admin/skill-maps
Body: { courseId: string, autoApprove?: boolean }

// Update skill map status
PATCH /api/admin/skill-maps
Body: { courseId: string, status: 'draft' | 'approved' | 'active' }

// Get skill map details
GET /api/admin/skill-maps/[courseId]
```

## Issues Encountered
