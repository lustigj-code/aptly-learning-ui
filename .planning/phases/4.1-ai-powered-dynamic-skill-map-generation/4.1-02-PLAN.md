**Gemini prompt for skill extraction:**
```
Analyze this course content and extract the key skills/competencies a learner will develop.

Course: {title}

For each module and lesson, identify:
1. The specific skills being taught (action verbs: "Identify...", "Apply...", "Create...")
2. The lesson ID where this skill is taught
3. The difficulty level (foundation/application/advanced)

Return JSON array:
[
  {
    "id": "{courseId}-M{module}-skill{n}",
    "name": "Skill description starting with action verb",
    "lessonId": "lesson-id",
    "difficulty": "foundation|application|advanced"
  }
]

Course content:
{serialized course content}
```

**Gemini prompt for prerequisites:**
```
Given these skills from a course, determine which skills are prerequisites for others.

Skills:
{list of skills with IDs and names}

For each skill, identify which OTHER skills must be learned first.
Return JSON object mapping skill ID to array of prerequisite skill IDs:
{
  "skill-id-1": [],  // No prerequisites
  "skill-id-2": ["skill-id-1"],  // skill-1 must be learned first
  ...
}

Rules:
- Earlier module skills typically prerequisite later ones
- Foundation skills prerequisite application skills
- Don't create cycles
```

**BKT parameter estimation:**
- Foundation skills: EASY_BKT_PARAMS (pL0: 0.2, pT: 0.4)
- Application skills: DEFAULT_BKT_PARAMS (pL0: 0.1, pT: 0.3)
- Advanced skills: HARD_BKT_PARAMS (pL0: 0.05, pT: 0.2)

Use structured output (JSON mode) to ensure parseable responses.
Handle Gemini errors gracefully - log and return partial results if possible.
