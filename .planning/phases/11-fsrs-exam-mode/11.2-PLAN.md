# Phase 11.2: Exam Mode

**Phase:** 11 - FSRS Wiring + Exam Mode
**Plan:** 11.2 - Exam Date Scheduling & Readiness Projection
**Priority:** High (certification is core value proposition)
**Estimated Effort:** 3-4 hours

---

## Context

Certification exam preparation is a key user motivation. Users need:
1. To set their certification exam date
2. To see if they're on track for 95% retention by exam date
3. Review schedules adjusted to hit retention goals

**Existing Infrastructure:**
- FSRS `calculateRetrievability()` can compute retention probability
- FSRS `predictMasteryDecay()` forecasts when concepts drop below threshold
- UserPreferences type exists but lacks exam date

---

## Objective

Add Exam Mode: user sets certification date, system shows readiness projection and adjusts review workload.

### Task 2: Create Exam Readiness Calculator

**File:** `src/lib/mastery/examReadiness.ts`

Build functions to calculate exam preparedness:

```typescript
// Calculate overall readiness percentage
export function calculateExamReadiness(
  conceptMasteries: ConceptMastery[],
  examDate: Date
): number;

// Predict retention at exam date for each concept
export function predictRetentionAtDate(
  mastery: ConceptMastery,
  targetDate: Date
): number;

// Calculate required daily review count to hit target retention
export function calculateDailyWorkload(
  conceptMasteries: ConceptMastery[],
  examDate: Date,
  targetRetention: number
): {
  dailyReviewsNeeded: number;
  conceptsAtRisk: string[];
  daysUntilExam: number;
  onTrack: boolean;
};
```
