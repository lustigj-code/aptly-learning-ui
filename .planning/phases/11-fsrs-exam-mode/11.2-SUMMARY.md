### Task 2: Exam Readiness Calculator

**File:** `src/lib/mastery/examReadiness.ts`

Core functions for calculating exam preparedness:

- **`predictRetentionAtDate(mastery, targetDate)`** - Project retention using FSRS formula
- **`calculateExamReadiness(masteries, examDate, targetRetention)`** - Overall readiness score
  - Returns: overallReadiness, daysUntilExam, onTrack, dailyReviewsNeeded, conceptsAtRisk
- **`calculateDailyWorkload(masteries, examDate, targetRetention)`** - Required daily reviews
  - Includes suggested schedule for next 14 days
- **`getReadinessMessage(readiness)`** - Human-readable status messages

**Key Formula:**
Uses FSRS retrievability: `R(t) = (1 + t/(9*S))^(-1)`

        ▼
