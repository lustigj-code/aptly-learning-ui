# Phase 10.2: A/B Testing Dashboard Enhancements

**Phase:** 10 - Data Collection + A/B Enhancement
**Plan:** 10.2 - A/B Testing Dashboard UI
**Priority:** Medium (infrastructure exists, adding UX improvements)
**Estimated Effort:** 3-4 hours

---

## Context

The A/B testing infrastructure is already well-built:
- ✅ `src/lib/experiments/abTest.ts` - Full CRUD, variant assignment, results calculation
- ✅ `/api/admin/experiments/` - Complete admin API
- ✅ `/api/experiments/` - User assignment and config APIs
- ✅ `src/components/admin/ExperimentPanel.tsx` - Viewing experiments and results
- ✅ Admin dashboard with Experiments tab

**What's Missing:**
1. Experiment creation UI (currently API-only)
2. First experiment: Socratic Sage vs current coach
3. Interaction count display (monitoring data collection)

---

## Objective

Add experiment creation capabilities and create the first v2.0 experiment to measure Socratic coaching effectiveness.
