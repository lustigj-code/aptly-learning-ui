## What Was Built

### 1. InteractionLog Types (`src/types/index.ts`)
Added comprehensive types for ML model training data:
- `InteractionType` enum: quiz_answer, practice_response, content_view, hint_request, coach_interaction, review_attempt
- `InteractionLog` interface with 20+ fields for full learning context
- `InteractionLogInput` for type-safe inputs

### 2. Interaction Logging Service (`src/lib/services/interactionLogService.ts`)
Server-side Firestore service with:
- `logInteraction()` - Single interaction logging
- `batchLogInteractions()` - Batch logging (up to 500 per batch)
- `getInteractionsByUser()` - Query by user
- `getInteractionsBySkill()` - Query by skill (for BKT analysis)
- `getUserSkillInteractions()` - Combined user+skill queries
- `getInteractionCount()` - Monitoring data collection
- `getSessionInteractions()` - Session-scoped queries

### 3. useInteractionLogger Hook (`src/hooks/useInteractionLogger.ts`)
Client-side React hook providing:
- `logQuizAnswer()` - Log quiz responses with timing
- `logPracticeResponse()` - Log practice interactions
- `logContentView()` - Log content consumption
- `logHintRequest()` - Log hint usage
- `logCoachInteraction()` - Log AI coach messages
- `logReviewAttempt()` - Log FSRS review attempts

Features:
- Client-side batching (50 items or 10 seconds)
- Session ID management
- Time gap tracking between attempts
- Consecutive wrong answer tracking
- `sendBeacon` for page unload

### 4. API Endpoint (`src/app/api/interactions/log/route.ts`)
- `POST /api/interactions/log` - Batch log interactions
- `GET /api/interactions/log` - Get collection statistics
- Zod validation for all inputs
- Firebase auth verification

### 5. QuizAtom Integration (`src/components/learning/QuizAtom.tsx`)
- Added response time tracking (questionStartTimeRef)
- Logs every quiz answer submission
- Logs hint requests
- Captures: questionId, skillId, isCorrect, responseTimeMs, attemptNumber, difficulty

## Data Schema

Each interaction captures:
```typescript
{
  // Identity
  userId, sessionId, id

  // Learning Context
  courseId, moduleId, lessonId, atomId, atomType

  // Skill Context (for BKT/DKT)
  skillId, skillName, questionId

  // Response Data
  interactionType, isCorrect, selectedAnswer, correctAnswer

  // Timing (for forgetting curve)
  timestamp, responseTimeMs, timeGapFromLastAttempt

  // Attempt Context
  attemptNumber, consecutiveWrongOnSkill, hintsUsedBefore

  // Difficulty (for Rasch model)
  questionDifficulty, userAbilityEstimate

  // Mastery State (for supervision)
  pMasteryBefore, pMasteryAfter

  // Experiments
  experimentVariants
}
```
